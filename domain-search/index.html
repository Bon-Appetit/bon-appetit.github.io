FAQ

Choose a domain list, enter one or more search terms, and select Search. The app fetches the selected list, checks each non-empty line in your browser, and displays matching domains. Matching, sorting, highlighting, and result rendering all happen locally in your browser; the app does not send your searches to a server.

For one phrase, leave “Search multiple terms” off and enter it in the search field. To search several phrases, turn that option on and enter one term per line. The code trims each line and ignores blank lines, then matches a domain when any entered term matches it. You can enter up to 100 terms.

Enable “Regular expression” under Advanced options to use JavaScript regular-expression syntax. For example, ^abc matches domains beginning with abc, xyz$ matches ones ending in xyz, ^[a-z]{3}$ matches exactly three lowercase letters, and (foo|bar) matches either foo or bar. Invalid expressions are rejected before the list is searched.

Turn on “Exact match only” under Advanced options. A result is included only when the complete trimmed domain line equals a search term, ignoring letter case. Exact matching disables regular expressions and highlighting.

After a successful search, the “Copy permalink” button appears. It copies a link containing the list URL, search terms, and search options, so someone else can restore the same search. Because all of that information is encoded in the link, a permalink can be very long.
